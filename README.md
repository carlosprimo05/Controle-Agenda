**Welcome to your Supabase-powered project** 

**About**

This project now uses Supabase for application data and authentication.

This project contains everything you need to run your app locally.

**Edit the code in your local development environment**

1. Clone the repository using the project's Git URL
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env` file with your Supabase credentials

Example `.env`:

```
VITE_SUPABASE_URL=https://vuzrhhzssetakpzwctmg.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

Run the app: `npm run dev`
